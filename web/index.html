02 / LIVE CHAIN EVIDENCE

Inspect a NEAR transaction

Read the actual execution receipts, status and gas for a real transaction. No wallet or key required.

READ ONLY · LIVE RPC

Enter a transaction hash and the exact signer account. Results come from live read-only NEAR RPC data; they are not simulations or automatic vulnerability findings.

If a transaction has failed receipts, that is an observed execution result—not proof of an exploitable security bug. RPC access requires connectivity and may be subject to provider limits.

03 / CREATE A REPRODUCIBLE TEST

Build a NEAR Sandbox test plan

Prepare real method calls and state assertions without writing JSON. Export a validated plan for the isolated Sandbox CLI.

LOCAL PREPARATION · NO EXECUTION

Select a WASM file above to discover exported function names. Method and expected-state inputs must match your contract.

This editor only generates a test plan. To execute the compiled contract and collect real receipts, run the Sandbox CLI in a disposable environment. Browser exports never prove contract safety.
